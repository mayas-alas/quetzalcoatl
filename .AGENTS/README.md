# Agent execution contract — 0.1.12

This directory scopes the three independent delivery roles used for the 0.1.12 MVP consolidation. It records implemented decisions and evidence requirements; it is not a future-platform roadmap.

Roles:

1. `runtime-transport.md` — typed Fedora operations and bounded process transport.
2. `reconciler-recovery.md` — convergence ordering, persistence and resume behavior.
3. `release-integrity.md` — versions, payload, WiX build and cross-role validation.
