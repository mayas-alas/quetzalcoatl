# Quetzalcoatl 0.1.12

Quetzalcoatl is a Windows 11 bootstrap and convergence service for one managed Fedora Podman Machine running a Tailscale-connected Proxmox VE cluster node.

Version 0.1.12 consolidates the MVP around four Rust crates, one exact runtime payload, a typed on-demand Fedora agent, resumable controller/member reconciliation and a deterministic WiX build.
