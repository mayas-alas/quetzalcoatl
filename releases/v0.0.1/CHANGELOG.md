# GnX Core v0.0.1 — preliminar

- CLI/servicio Windows Rust con pipe local protegido.
- Frontera de identidad dedicada para WSL y lifecycle delegado a systemd.
- Verificador SHA-256 de payload offline.
- Fuentes de MSI/EXE, cuatro Quadlets e integración de base Fedora bootc.

**Esta versión del binario no equivale a un nodo instalado o aceptado.**
Instalación/HTTPS, configuración de credenciales por CLI y despliegue LXC/OIDC
no están aceptados. No sustituye el legacy ni es una release de producción.
