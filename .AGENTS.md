# Agent entrypoint

Read `.AGENTS/00-scope.md`, `.AGENTS/40-config-driven-deployments.md`, then your owned task file. The config-driven deployment paradigm is mandatory: no live hotfixes, ad hoc temporary runners or per-app control planes. Deliver source → build → installed CLI lifecycle → tests/restart/browser evidence → verified publication → owned cleanup. Keep commits small, push after every validated milestone, and do not edit another agent’s owned paths. Implementation workers use `gpt-5.6-luna` with **high** effort; report unavailable model/tooling instead of silently substituting.
